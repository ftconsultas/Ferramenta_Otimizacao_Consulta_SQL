Análise de Plano Real (Modo Detalhado)

Para obter o plano de execução, é necessário conectar-se a um banco de dados.

MySQL

Custo por Iteração (Loops)

O actual time do MySQL é uma média por loop. Nossa ferramenta já multiplica o tempo final pelo número de loops para te dar o Tempo Total Real daquela etapa.

Decomposição de Tempo (Delta)

Isolamos o custo de cada etapa subtraindo o tempo dos "filhos" do tempo do "pai". O valor Delta é o que aquela operação específica (como um Filtro ou Join) custou de verdade.

Latência de Inicialização

A barra de progresso mostra a diferença entre a Primeira Linha (Barra Amarela) e o Total (Barra Azul). Se a barra amarela for muito grande, o banco está "travado" preparando dados antes de começar a entregar os resultados para aquela operação.
