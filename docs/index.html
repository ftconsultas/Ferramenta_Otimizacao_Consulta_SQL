Principais Funcionalidades

Projetado para ensinar otimização de banco de dados de forma transparente e visual

1. Análise Estática Offline (AST)

Inspeciona a consulta sem precisar de conexão com o banco, detectando 17 antipadrões (SELECT *, funções no WHERE, LIKE '%...', JOIN implícito, subconsultas correlacionadas e mais).

2. Decomposição de Tempo Delta

Executa o EXPLAIN ANALYZE real no MySQL 8.0+ e subtrai o tempo dos nós filhos para revelar exatamente qual etapa física é o verdadeiro gargalo da consulta.

3. Scorecard Antes vs. Depois

Compara lado a lado o plano original e o plano refatorado, exibindo diff léxico do SQL, ganho de velocidade (speedup), redução de custo e Table Scans eliminados.

4. Segurança e Criptografia Local

Conexão restrita a localhost com credenciais criptografadas via chaveiro nativo do sistema operacional (safeStorage) e isolamento estrito de contexto.

Como executar no seu sistema

Windows (x64)

Extraia o arquivo .zip baixado e dê duplo clique no executável:

SQL Optimizer.exe
Linux (.AppImage ou .deb)

Dê permissão de execução ao AppImage ou instale o pacote .deb:

chmod +x Ferramenta_educacional_para_otimizacao_de_consultas_SQL-Linux-x86_64.AppImage && ./Ferramenta_educacional_para_otimizacao_de_consultas_SQL-Linux-x86_64.AppImage --no-sandbox
macOS (.zip)

Extraia o arquivo .zip e abra o aplicativo (se necessário, remova a quarentena):

xattr -cr "SQL Optimizer.app" && open "SQL Optimizer.app"
